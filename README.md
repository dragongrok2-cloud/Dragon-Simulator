# 🐉 Dragon Simulator

Добро пожаловать в **Dragon Simulator** — захватывающий симулятор жизни могучего дракона!

## О проекте

Стань настоящим драконом: летай по небу, дыши огнём, охоться, защищай свою территорию и исследуй огромный мир.

### Возможности (план):
- Реалистичный полёт и физика
- Система дыхания огнём / льдом / молнией
- Охота и выживание
- Строительство логова
- Разные биомы и погода
- Режим свободного полёта

## Как запустить

Проект только начинается. Код появится совсем скоро!

```bash
# Клонировать репозиторий
git clone https://github.com/dragongrok2-cloud/Dragon-Simulator.git

```
