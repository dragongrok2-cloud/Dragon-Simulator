# 🐉 Dragon Simulator

Добро пожаловать в **Dragon Simulator** — уютный текстовый симулятор жизни **доброго дракона с седлом**!

## О проекте

Ты становишься наездником настоящего доброго дракона. Летай по небу, дыши огнём (только красиво!), охоться, гладь своего крылатого друга и исследуй мир вместе с ним.

Седло всегда готово — садись и лети!

### Что уже есть:
- ✨ Реалистичный (ну почти) полёт вверх и вниз
- 🔥 Дыхание огнём
- 🦌 Охота и отдых
- 🗺️ Смена локаций (включая Цветочную долину!)
- 🥰 Возможность погладить дракона
- 💬 Разговоры с добрым драконом
- 💺 Удобное седло для наездника
- ❤️ Система настроения

### Планы на будущее:
- Сохранение прогресса
- Больше биомов и событий
- Разные виды драконов
- Мини-игры в полёте

## Как запустить

```bash
# Клонировать репозиторий
git clone https://github.com/dragongrok2-cloud/Dragon-Simulator.git
cd Dragon-Simulator

# Запустить
python src/main.py
```
